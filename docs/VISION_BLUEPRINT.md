# Praxis Vision Blueprint

当前产品长期定义以 [PRODUCT_BLUEPRINT_V1.md](./PRODUCT_BLUEPRINT_V1.md) 为准。

这个入口文档只负责收口“哪份文档是当前愿景基线”，避免后续继续把旧版通用 Todo/人生管理文档混入当前产品判断。

## 当前基线

- Canonical vision: `PRODUCT_BLUEPRINT_V1.md`
- 当前路线：`个人成长闭环产品`，不是泛管理工具合集
- 目标闭环：`Intent -> AI 规划 -> 编排 -> 执行 -> 反馈 -> 奖励兑现 -> 复盘 -> 下一轮`

## 版本分层

- `Alpha`
  - 本地主链 + Web 可完整体验
  - 核心闭环可走通
- `Beta`
  - 账号、云端数据、托管 AI、Web + Android 稳定
- `Public v1`
  - 奖励闭环、节奏编排、公开分享与上线准备完成

## 文档使用约束

- 讨论产品愿景、对象边界、奖励哲学时，引用 `PRODUCT_BLUEPRINT_V1.md`
- 讨论首个公开版本范围、接口和验收时，引用 `LAUNCH_SPEC_V1.md`
- 旧版路线图和项目总结只作为历史记录，不再作为当前实现依据
