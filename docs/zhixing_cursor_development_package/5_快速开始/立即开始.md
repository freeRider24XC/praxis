## 🎯 第一步：品牌升级（30分钟）

### 1.1 更新项目配置
打开 `pubspec.yaml`，按照 `3_源代码文件/pubspec.yaml建议修改.md` 进行修改：

```yaml
# 主要修改
name: zixing  # 从 praxis 改为 zixing
description: "知行合一，规划人生 - 智能AI规划助手"
version: 2.0.0+1
```

### 1.2 替换主题系统
```bash
# 复制新主题文件
cp 3_源代码文件/lib/common/style/themes.dart /your_project/lib/common/style/
```

### 1.3 更新应用标题
在 `lib/main.dart` 中：
```dart
// 修改前
title: "Praxis",

// 修改后  
title: "ZhiXing (知行)",
```

### 1.4 测试运行
```bash
flutter clean
flutter pub get
flutter run
```

✅ **检查点**: 应用启动后应显示 "ZhiXing (知行)" 标题

## 🎨 第二步：UI组件升级（2-3小时）

### 2.1 集成新组件库

### 2.2 替换现有组件
逐步替换现有页面中的组件：

    ],

### 2.3 页面升级示例

## 🤖 第三步：AI服务集成（1-2天）

### 3.1 集成AI服务
```bash
# 复制AI服务文件
cp 3_源代码文件/lib/common/ai/services/zixing_ai_service.dart /your_project/lib/common/ai/services/
```

### 3.2 注册服务
在 `lib/main.dart` 中添加：
```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 注册AI服务
  await Get.putAsync(() => ZhiXingAIService().onInit().then((_) => ZhiXingAIService()));
  
  runApp(MyApp());
}
```

### 3.3 配置AI提供商
根据您的AI服务提供商配置相应的API密钥。

### 3.4 测试AI功能
参考 `4_代码示例/AI服务集成示例.md` 测试各个AI功能。

## 🔧 第四步：问题排查

### 常见问题及解决方案

#### 问题1: 导入错误
**错误**: `Target of URI doesn't exist`
**解决**: 
```dart
// 检查导入路径是否正确
import 'package:praxis/common/widgets/zixing_widgets.dart';
```

#### 问题2: 主题不生效
**错误**: 界面样式没有变化
**解决**:
```dart
// 确保使用正确的GetMaterialApp配置
GetMaterialApp(
  theme: ZhiXingTheme.lightTheme,
  darkTheme: ZhiXingDarkTheme.darkTheme,
  // ...
)
```

#### 问题3: AI服务调用失败
**错误**: AI功能无法使用
**解决**:
1. 检查网络连接
2. 验证API密钥配置
3. 查看控制台错误日志
