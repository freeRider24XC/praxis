# Praxis · 人生无限公司

> 你的第二大脑 — 用玩游戏的方式过好人生

**版本：** v2.0（基于 Life·X 理念重构）
**日期：** 2026-05-04
**状态：** 待开发

---

## 一、产品愿景

### 1.1 一句话定位

Praxis 是一款**游戏化人生管理系统**，帮助用户把"经营自己的人生"变成一件有反馈、有成长、有成就感的事情。

### 1.2 核心理念

> **把人生当游戏，把目标当副本，把每天当一次闯关。**

- 不是"更全能的 Todo App"，而是"人生角色扮演成长系统"
- 不是记录工具，而是执行驱动工具
- 不是让你看数据，而是让你想打开 App

### 1.3 目标用户

| 用户画像 | 描述 |
|---------|------|
| 核心用户 | 22-30岁，有自我提升意愿，但执行力差、容易半途而废 |
| 次要用户 | 有明确目标但缺乏系统管理工具的知识工作者 |
| 场景 | 想系统管理人生（不只是 Todo），希望有游戏化反馈 |

### 1.4 与现有 Todo App 的核心差异

| 维度 | 现有 Todo App | Praxis |
|------|--------------|--------|
| 定位 | 任务记录工具 | 人生操作系统 |
| 核心 | Todo + Goal + Project | 人生领域 + 角色等级 + 目标体系 |
| 动力 | 靠意志力 | 靠游戏化（等级/XP/成就） |
| 视角 | 低头做事 | 抬头看全局 |
| 粘性 | 用完即走 | 每天想打开 |

## 三、核心数据模型

### 3.1 现有模型（已实现）

以下模型已在代码中完整实现，继续使用：

- **Todo** — 任务（标题、优先级、截止日期、项目关联、目标关联、子任务、重复规则）
- **Goal** — 目标（年度/季度/月度/周/自定义，含 Key Results + 里程碑）
- **Project** — 项目（含阶段 phases，含健康度 health 计算）
- **FocusSession** — 专注记录（时长、完成状态）
- **UserStats** — 用户统计（已完成任务数、专注时长等）

### 4.2 AI 目标拆解（核心差异化功能）

**产品位置：** 首页 FAB → AI 对话页

#### 交互流程

```
用户输入："我想今年跑一次半马"

→ AI 分析：
   - 识别这是「健康身体」领域
   - 识别这是一个模糊的大目标
   - 生成 3 个追问：
     1. 你现在有跑步习惯吗？
     2. 计划在几个月内完成？
     3. 你的体重/体能基础怎样？

用户回答后 → AI 生成：
   - 主目标：「2026年完成半程马拉松」
   - 拆解为季度里程碑：
     Q2：连续跑步4周，每周3次
     Q3：完成10公里
     Q4：完成半马训练并参赛
   - 生成本周第一个 Todo：
     「周一慢跑3公里，测试当前体能」
   - 奖励 XP：+20（目标制定）

→ 自动创建：
   - Goal（目标）
   - Project（项目：半马训练计划）
   - 若干 Todo（本周任务）
   - XP 事件记录
```

#### AI Prompt 设计要点

```
系统角色：你是一个人生无限公司的 CEO 助理，
帮助用户将模糊的人生目标拆解为可执行的 Todo/Goal/Project。
每次拆解后，根据任务类型奖励用户 XP。

拆解原则：
1. 大目标 → 季度里程碑 → 月计划 → 周任务 → 日 Todo
2. 每个 Todo 必须关联到一个「人生领域」
3. 拆解完成后，给出 XP 奖励建议
4. 用公司语言：任务=项目立项，todo=执行工单，里程碑=季度汇报
```

## 五、XP 等级系统

### 5.1 XP 来源

| 行为 | XP | 归属领域 |
|------|-----|---------|
| 完成一个 Todo | +10 | 继承 Todo → Project → Goal 的领域 |
| 完成一个 Key Result | +30 | 同上 |
| 完成一个 Goal | +100 | 同上 |
| 完成一个番茄钟（25分钟） | +10 | 同上 |
| 完成每日复盘 | +20 | 平均分配到各领域 |
| 解锁一个成就 | +成就 XP | 无固定领域 |
| 连续活跃 7 天 | +50 | 平均分配 |
| 连续活跃 30 天 | +200 | 平均分配 |
| 早上6点前完成 Todo | +20 | 对应领域 |
| 提前2天完成 Todo | +15 | 对应领域 |

### 5.2 等级计算

```
每级所需 XP = 100 + (level × 50)

Lv.1  → Lv.2： 150 XP
Lv.2  → Lv.3： 200 XP
Lv.3  → Lv.4： 250 XP
...
Lv.12 → Lv.13： 700 XP
```

### 5.3 等级称号

| 等级范围 | 称号 |
|---------|------|
| Lv.1-5 | 见习生 |
| Lv.6-10 | 实习生 |
| Lv.11-20 | 规划专员 |
| Lv.21-30 | 项目经理 |
| Lv.31-50 | 部门总监 |
| Lv.51-70 | 执行董事 |
| Lv.71-90 | CEO |
| Lv.91-100 | 人生赢家 |

## 九、竞品分析

| 产品 | 定位 | 差异点 |
|------|------|--------|
| Notion | 人生管理系统（Notion模板） | 无游戏化，无移动端，无推送 |
| Habitica | 游戏化习惯养成 | 只有习惯（Habit），没有人生维度 |
| Todoist | 任务管理 | 无游戏化，无人生视角 |
| 滴答清单 | 任务+日历 | 无游戏化，无人生维度 |
| 各类 OKR App | OKR 管理 | 无游戏化，界面枯燥 |

**Praxis 的护城河：** 国内市场没有"游戏化 + 人生五维 + AI 目标拆解"三者结合的移动端 App。
