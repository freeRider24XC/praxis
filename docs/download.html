为什么不是普通待办工具

Praxis 不想让你维护一个越来越复杂的系统，而是让你每天知道自己最该推进哪一步， 并且在完成努力后真的奖励自己，而不是只被打分。

先抓主线 第一次进入先说最近最想拉起来什么，而不是先填一堆结构。
再排进现实 目标不是只拆成任务，还要根据本周可投入时间变成真实节奏。
奖励必须兑现 完成行动后攒到的是犒赏点，兑换奖励后还会生成奖励待办。

体验说明

Web 版和移动端有什么区别？

Web 版是当前最适合公开分享的入口，移动端更适合深度体验执行和日程场景。首轮建议先从 Web 进入。

这是不是已经正式上线？

还不是最终正式版，但已经具备公开预览所需的产品叙述、体验入口和部署样板。

我的数据会怎样处理？

请在使用前阅读隐私政策和用户协议。正式对外时，应以你部署环境所对应的实际数据与模型供应商为准。
