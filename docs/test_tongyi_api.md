## 测试步骤

### 1. 获取通义千问 API Key

1. 访问：https://dashscope.aliyun.com/
2. 使用阿里云账号登录（如果没有，先注册）
3. 开通 DashScope 服务
4. 进入控制台 → API密钥管理
5. 创建新的 API Key（格式类似：`sk-xxxxx...`）

### 2. 在应用中配置

1. 打开应用 → 设置页面
2. 找到"AI配置"卡片
3. 选择"通义千问 (免费额度)"
4. 输入刚才获取的 API Key
5. 点击"保存配置"

### 3. 测试连接

保存后会自动测试连接：
- ✅ **成功**：显示绿色提示"API密钥配置成功"
- ⚠️ **警告**：显示橙色提示，说明具体错误原因
- ❌ **错误**：显示红色提示，说明配置失败

### 4. 测试 AI 聊天功能

1. 返回主界面
2. 点击 AI 助手按钮（机器人图标）
3. 发送测试消息，例如：
   - "你好"
   - "帮我创建一个待办事项：明天上午10点开会"
   - "我想制定一个学习目标"

## 常见问题排查

### 问题1：测试连接失败 - API密钥无效
- 检查 API Key 是否正确复制
- 确认 API Key 是否已激活
- 检查是否有权限访问 DashScope 服务

### 问题2：测试连接失败 - HTTP 402
- 账户余额不足，需要充值
- 或者免费额度已用完

### 问题3：测试连接失败 - HTTP 429
- API 调用次数超限
- 等待一段时间后重试

### 问题4：请求超时
- 检查网络连接
- 确认防火墙设置
- 尝试使用 WiFi 而非移动网络

## 通义千问 API 信息

- **API 端点**：`https://dashscope.aliyuncs.com/api/v1`
- **默认模型**：`qwen-turbo`
- **API 格式**：兼容 OpenAI API 格式
- **认证方式**：Bearer Token（`Authorization: Bearer <api_key>`）
