# Praxis 项目功能梳理文档

**版本：** v1.0  
**更新日期：** 2024年  
**数据存储：** 本地存储（Hive），暂不涉及后端交互

---

## 📱 一、应用架构概览

### 1.1 技术栈
- **框架：** Flutter 3.32.8
- **状态管理：** GetX
- **本地数据库：** Hive
- **UI设计：** Material 3 + 自定义设计系统
- **国际化：** 支持中英文

### 1.2 核心设计理念
- **极简输入：** 降低用户输入成本
- **智能拆解：** AI辅助将想法转化为可执行计划
- **沉浸执行：** 专注模式帮助用户深度工作

## 🗂️ 二、数据模型（本地存储）

### 2.1 Todo（待办事项）
```dart
- id: String
- title: String
- description: String?
- createdAt: DateTime
- dueDate: DateTime?
- isDone: bool
- priority: TodoPriority (low/medium/high/urgent)
- tags: List<String>?
- projectId: String?
- goalId: String?
- completedAt: DateTime?
- reminderTime: DateTime?
- subTasks: List<String>?
- parentId: String?
```

### 2.2 Goal（目标）
```dart
- id: String
- title: String
- description: String?
- type: GoalType (yearly/quarterly/monthly/weekly/custom)
- startDate: DateTime
- targetDate: DateTime
- status: GoalStatus (notStarted/inProgress/paused/completed/cancelled)
- progress: double (0.0-1.0)
- category: String?
- milestones: List<String>?
- keyResults: List<KeyResult>?
- parentGoalId: String?
- subGoalIds: List<String>?
- linkedTodoIds: List<String>?
- targetValue: int?
- currentValue: int?
- unit: String?
```

### 2.3 Project（项目）
```dart
- id: String
- name: String
- description: String?
- status: ProjectStatus (planning/active/onHold/completed/cancelled/archived)
- startDate: DateTime
- endDate: DateTime?
- color: String
- icon: String?

- goalIds: List<String>?
- phases: List<ProjectPhase>?
- progress: double (0.0-1.0)
- tags: List<String>?
- createdAt: DateTime
- updatedAt: DateTime
- notes: String?

```

### 2.4 KeyResult（关键结果）
```dart
- id: String
```

## 🔄 四、核心交互流程

### 4.1 创建待办事项流程
```
首页/待办页 → 点击FAB/添加按钮 → 打开添加待办页
→ 输入标题 → 选择优先级/截止日期（可选）
→ 添加标签（可选）→ 关联项目/目标（可选）
→ 点击保存 → 保存到本地数据库 → 返回列表页 → 刷新列表
```

### 4.2 AI生成计划流程
```
首页 → 点击FAB → 进入AI交互页
→ 输入目标描述 → 选择标签（可选）
→ 点击"开始智能规划" → AI服务处理
→ 提取实体（Todo/Goal/Project）→ 保存到本地数据库
→ 显示成功提示 → 返回首页 → 刷新数据
```

### 4.3 执行任务流程
```
项目详情页 → 查看任务列表 → 点击任务勾选完成
→ 或点击"继续执行" → 进入专注模式
→ 选择白噪音（可选）→ 开始倒计时
→ 完成任务 → 返回项目详情页 → 更新进度
```

### 4.4 创建目标流程
```
目标列表页 → 点击添加按钮 → 打开添加目标页
→ 输入目标标题 → 选择目标类型/日期
→ 添加关键结果（可选）→ 添加里程碑（可选）
→ 点击保存 → 保存到本地数据库 → 返回列表页
```

## 📊 五、数据存储架构

### 5.1 数据库服务（DatabaseService）
**功能：**
- ✅ Hive数据库初始化
- ✅ Todo CRUD操作
- ✅ Goal CRUD操作
- ✅ Project CRUD操作
- ✅ 设置存储管理
- ✅ 数据备份与恢复

**主要方法：**
```dart
// Todo操作
- addTodo(Todo todo)
- getAllTodos()
- getTodosForToday()
- getTodosByProject(String projectId)
- getTodosByGoal(String goalId)
- getTodoById(String id)
- updateTodo(Todo todo)
- deleteTodo(Todo todo)

// Goal操作
- addGoal(Goal goal)
- getAllGoals()
- getActiveGoals()
- getGoalsByType(GoalType type)
- updateGoal(Goal goal)
- deleteGoal(Goal goal)

// Project操作
- addProject(Project project)
- getAllProjects()
- getActiveProjects()
- getProjectById(String id)
- updateProject(Project project)
- deleteProject(Project project)

// 设置操作
- getSetting(String key, {dynamic defaultValue})
- setSetting(String key, dynamic value)
- removeSetting(String key)
```

### 5.2 数据持久化
- **存储位置：** 本地Hive数据库
- **数据格式：** Hive对象序列化
- **备份机制：** `backupData()` 和 `restoreData()` 方法
