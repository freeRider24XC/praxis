# Praxis 交互流程图

## 📱 应用入口流程

```
App启动
  ↓
检查是否首次启动（SharedPreferences）
  ↓
是 → 显示启动页（OnboardingPage）
  │   ↓
  │   点击"开始探索"
  │   ↓
  └──→ 进入主页面（MainPage）
  ↓
否 → 直接进入主页面（MainPage）
```

## ✅ 待办事项完整流程

### 流程1：添加待办事项
```
待办列表页（TodoPage）
  ↓
点击FAB/添加按钮
  ↓
打开添加待办页（AddTodoPage）
  ↓
输入标题（必填）
  ↓
选择优先级/截止日期（可选）
  ↓
添加标签（可选）
  ├── 输入标签 → 按回车/点击添加
  └── 点击标签关闭按钮删除
  ↓
关联项目/目标（可选）
  ├── 点击"选择项目" → 底部弹窗选择
  └── 点击"选择目标" → 底部弹窗选择
  ↓
点击"保存待办事项"
  ↓
DatabaseService.addTodo() → 保存到Hive
  ↓
返回待办列表页 → 刷新列表
```

### 流程2：快捷添加任务
```
首页/任意页面
  ↓
点击FAB按钮
  ↓
打开快捷任务弹窗（QuickAddModal）
  ↓
输入任务标题
  ↓
选择快捷标签（今天/高优先级/AI润色）
  ↓
点击"创建任务"
  ↓
DatabaseService.addTodo() → 保存到Hive
  ↓
关闭弹窗 → 刷新数据
```

### 流程3：完成任务
```
待办列表页
  ↓
点击任务复选框
  ↓
切换isDone状态
  ↓
DatabaseService.updateTodo() → 更新Hive
  ↓
刷新列表显示
```

## 🤖 AI交互完整流程

### 流程1：AI生成计划
```
首页
  ↓
点击FAB按钮
  ↓
进入AI交互页（AiInteractionPage）
  ↓
输入目标描述（例如："我想在一个月内瘦5斤"）
  ↓
选择标签（可选：运动健身/技能学习/旅行规划）
  ↓
点击"开始智能规划"
  ↓
AiService.sendMessage() → 调用OpenAI API
  ↓
EntityExtractor.extractFromResponse() → 解析响应
  ↓
提取实体（Todo/Goal/Project）
  ↓
DatabaseService.addTodo/addGoal/addProject() → 保存到Hive
  ↓
显示成功提示
  ↓
返回首页 → 刷新数据
```

```
  ↓
倒计时结束/点击停止/点击跳过

```

## 🔄 数据流转图

```
用户操作
  ↓
UI组件（Page/Widget）
  ↓
业务逻辑处理
  ↓
DatabaseService（数据服务层）
  ↓
Hive数据库（本地存储）
  ↓
数据持久化
```

**示例：添加待办事项**
```
AddTodoPage（UI）
  ↓
用户输入数据
  ↓
_saveTodo()方法
  ↓
DatabaseService.addTodo()
  ↓
Hive数据库保存
  ↓
返回成功 → 刷新列表
```

## 📊 数据关联关系

```
Project（项目）
  ├── todoIds → Todo[]
  ├── goalIds → Goal[]
  └── phases → ProjectPhase[]
      └── todoIds → Todo[]

Goal（目标）
  ├── linkedTodoIds → Todo[]
  ├── keyResults → KeyResult[]
  └── milestones → String[]

Todo（待办）
  ├── projectId → Project
  ├── goalId → Goal
  └── tags → String[]
```
